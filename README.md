# BMI Calculator V1.0 🧮💪

A simple and elegant **Body Mass Index (BMI)** calculator built using Python's `tkinter` GUI library. This desktop app allows users to calculate their BMI based on their **age**, **height**, **weight**, and **gender**, and provides a quick health status overview.

## 🧠 What is BMI?

**BMI (Body Mass Index)** is a measure that uses your height and weight to estimate whether you're underweight, normal, overweight, or obese. It's a widely used screening tool in health and fitness.

---

## 🚀 Features

- 🧍 Gender selection (Male / Female)
- 🧓 Age input validation
- 📏 Height (in cm) and ⚖️ Weight (in kg) inputs
- 📊 Accurate BMI calculation with health category:
  - Underweight
  - Normal weight
  - Overweight
  - Obese
- 🔄 Clear/reset fields
- 🪄 User-friendly, responsive interface with a clean design
- 💙 Designed with `tkinter` and the Cairo font (if available)

---

## 📦 Requirements

- Python 3.x
- tkinter (included by default in standard Python installations)

## 🛠️ How to Run

1. **Clone this repository**:

```bash
git clone https://github.com/yourusername/bmi-calculator-v1.0.git
cd bmi-calculator-v1.0
python3 BMI Calculator V1.0.py
```
**Make sure you have Python 3 installed. You can download it from python.org.**

**📌 Notes**
This is a basic version designed for learning and demonstration purposes.

The gender and age fields are included but currently not factored into the BMI formula (standard BMI does not use them).

The UI font is set to "Cairo". You can change it to a default system font (like Arial) if Cairo is not installed.
